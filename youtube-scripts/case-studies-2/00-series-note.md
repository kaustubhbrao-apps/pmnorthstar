## House rules (same as series 1)
- Open with a hook that sells the brand + a tension, never hype. The hook is the FIRST
  thing said — no "welcome to this explainer," no "in this video," no title read-out. Cold
  open straight into the story, YouTube-style; "I'm EV, from pmnorthstar" comes after the
  hook, never before. (When generating in NotebookLM, paste the bible's delivery prompt so
  it doesn't add its own intro.)
- Teach ONE core product principle per video; name it, prove it with the brand's real moves, generalize it so it transfers.
- Positive framing; name a hard moment only as setup for the win.
- Global audience: gloss any India/region-specific reference in one line.
- Land one interview takeaway per video ("in a case, you'd say…").
- Keep numbers directional, not invented.
- Target ~1,450–1,650 spoken words, brisk pace, fast transitions. Density is the feature.
- Each script carries a "WHERE THEY ARE NOW (2025–26)" beat and a top-of-file **brand
  visual kit** (signature colors + logo motif + imagery) for the animation pass.
